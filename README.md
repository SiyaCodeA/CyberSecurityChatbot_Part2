# Cyber Security Awareness Chatbot – Part 2

## Project Overview

This project is a Cyber Security Awareness Chatbot developed using C# and WPF.
The chatbot educates users about cybersecurity topics such as:
- phishing
- password safety
- online scams


The application includes sentiment detection, memory recall and dynamic responses to improve conversational flow and user interaction.

## Features

- WPF graphical user interface
- Dynamic/random chatbot responses
- Sentiment detection
- Memory recall
- Cybersecurity awareness tips
- ASCII art welcome screen
- Input validation
- Object-oriented programming structure
- GitHub version control with releases

## Technologies Used

- C#
- WPF
- Visual Studio
- GitHub

## Setup Instructions

1. Download or clone the repository
2. Open the solution in Visual Studio
3. Run the project using F5

## Usage Examples

User: password
Chatbot: Enable two-factor authentication.

User: phishing
Chatbot: Never click suspicious email links.

User: I am worried about scams
Chatbot: I understand your concern. Scammers often pressure users urgently.
